# Αναφορά μικροβιώματος → προσαρμογή συνταγών

Σελίδα (στα ελληνικά) για διατροφολόγο: ανεβάζεις την αναφορά μικροβιώματος (PDF της The BioArte), διαβάζονται οι πίνακες «Τροφές προς προτίμηση» και «Τροφές προς μείωση», και κάθε ενσωματωμένη συνταγή ελέγχεται υλικό προς υλικό, με προτάσεις αντικατάστασης. Επιλέγεις συνταγές ανά γεύμα και κατεβάζεις έγγραφο PDF για τον ασθενή.

Όλα τρέχουν μέσα στον browser: η αναφορά δεν ανεβαίνει πουθενά. Η αντιστοίχιση γίνεται με λεξικό τροφίμων (λέξεις-κλειδιά), όχι με AI.

## Δομή

```
index.html              markup της σελίδας· φορτώνει τα css/js με τη σειρά που χρειάζονται
css/base.css            βασικό reset (το ίδιο που προσθέτει το claude.ai γύρω από τα artifacts)
css/styles.css          όλη η εμφάνιση (χρώματα ως tokens, light/dark)
js/food-dictionary.js   το λεξικό: μία γραμμή ανά τροφή (μοτίβα αναφοράς/συνταγής, εξαιρέσεις, πιθανή αντιστοίχιση, αντικαταστάσεις)
js/matching.js          μηχανή αντιστοίχισης: αναφορά → λεξικό, έλεγχος υλικών, προτάσεις
js/report-parser.js     ανάγνωση του PDF (pdf.js): πίνακες, υπερτροφές, αριθμός αναφοράς, όνομα ασθενούς
data/recipes.js         οι ενσωματωμένες συνταγές (παράγεται από το Excel — μην το επεξεργάζεσαι με το χέρι)
js/pdf-fonts.js         γραμματοσειρές για το PDF (base64)
js/app.js               κατάσταση, ανάλυση, εμφάνιση λίστας/συνταγών, φίλτρο πηγής
js/selection.js         επιλογή ανά γεύμα, έγγραφο ασθενούς (HTML), προεπισκόπηση
js/pdf-export.js        PDF με πραγματικό κείμενο (pdfmake)
js/events.js            χειρισμός φίλτρων και λίστας
js/upload.js            ανέβασμα αναφοράς, προσωρινή αντικατάσταση συνταγών από .xlsx
js/excel-export.js      εξαγωγή Excel και αποθήκευση αρχείων
js/ai-rewrite.js        προαιρετικό: το Claude ξαναγράφει την εκτέλεση (μόνο μέσα στο claude.ai)
js/main.js              εκκίνηση
scripts/                build_recipes.py, bundle.py, make_fonts.sh
tests/                  e2e.py (browser), dictionary_sample.js (έλεγχος λεξικού)
```

Τα αρχεία js είναι απλά `<script>` (όχι modules) και μοιράζονται τα ονόματα μεταξύ τους, οπότε η σειρά στο `index.html` μετράει.

## Συχνές εργασίες

**Νέες συνταγές** (ίδια μορφή Excel: φύλλα «Συνταγές» και «Υλικά»):
```
python3 scripts/build_recipes.py path/to/Συνταγές_diatrofi.xlsx
```

**Αλλαγή/προσθήκη τροφής στο λεξικό:** στο `js/food-dictionary.js`. Μετά δες τι πιάνει στις συνταγές:
```
node tests/dictionary_sample.js <κωδικός τροφής>
```

**Έλεγχος σε browser** (θέλει `pip install playwright` και `playwright install chromium`):
```
python3 tests/e2e.py index.html path/to/report.pdf
```
Οι αναφορές έχουν προσωπικά δεδομένα — μην τις ανεβάζεις στο repo (`*.pdf` είναι στο `.gitignore`).

**Ένα αρχείο** (για το claude.ai artifact ή για αποστολή):
```
python3 scripts/bundle.py      →  dist/artifact.html, dist/index.html
```

## Φιλοξενία

GitHub Pages: Settings → Pages → Deploy from branch → `main` / root. Σερβίρει απευθείας το `index.html` με τους φακέλους· δεν χρειάζεται bundle. Εκεί η εξαγωγή PDF/Excel κατεβαίνει κανονικά, χωρίς λογαριασμό.

Μέσα στο claude.ai η αποθήκευση αρχείων γίνεται μόνο μέσω της λειτουργίας αποθήκευσης του claude.ai (όχι για μη συνδεδεμένους χρήστες).
